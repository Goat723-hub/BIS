# 视频审核系统(Video Moderation)

一个从零搭建的视频审核系统演示项目,完整跑通「识别违规 → 处置成合规」的闭环。

## 完整流程

```
视频进来
  ↓
① 抽帧(等间隔 + 场景切换检测)
  ↓
② 黑库比对(pHash 感知哈希)──命中 → 直接拦截
  ↓ 未命中
③ OCR 识别画面文字
  ↓
④ 敏感词打分(加权取最高)
  ↓
⑤ 阈值分档 → 拦截 / 转人工(灰色地带) / 放行
  ↓
⑥ 处置打码 → 违规字幕糊掉,输出合规视频
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `moderate.py` | 主程序:一条命令跑完整审核 |
| `blacklist.py` | 黑库模块(pHash 指纹 + 汉明距离比对) |
| `make_violate.py` | 合成违规视频(叠加违规字幕) |
| `sanitize.py` | 审核 + 打码,输出合规视频 |
| `extract_frames.py` | 抽帧模块 |
| `ocr_check.py` | OCR + 敏感词模块 |
| `moderation_scoring.py` | 打分 + 阈值分档模块 |
| `blacklist/` | 黑库目录(存违规指纹种子) |
| `before.jpg` / `after.jpg` | 打码前后对比截图 |

## 快速开始

```bash
# 1. 装依赖
pip install -r requirements.txt

# 2. 审核一个视频(输出审核报告)
python3 moderate.py 你的视频.mp4

# 3. 生成违规/合规对比视频
python3 make_violate.py   # 合成违规视频(叠加字幕)
python3 sanitize.py       # 识别违规字幕并打码,输出合规视频
```

## 技术原理(讲人话)

- **抽帧**:等间隔 + 场景切换,不漏关键画面也不浪费算力
- **黑库(pHash)**:感知哈希指纹,汉明距离比对,秒认"同源违规内容"
- **OCR**:识别画面文字,交给敏感词判断
- **打分**:敏感词带权重,命中取最高分(避免长视频累加误判)
- **分档**:高分拦截、中分转人工(灰色地带)、低分放行
- **打码**:定位违规文字区域,高斯模糊

## 核心思想

**层层设防**:没有任何一道是 100% 可靠,所以用多道一起兜(黑库、OCR、打分、人工、申诉)来逼近 100%。
